# DWG 上传解析失败排查

## 复现与原因

2026-09-10，生产任务 `cad_bb814f4e759a4c2496ab5c477de9288d` 上传 AC1032（AutoCAD 2018+）DWG 后，在 0.174 秒内返回 `dxf_parse_failed`。原文件保存在任务目录，大小 81535 字节，SHA-256 为 `0048836b34a98e6fe2b1a2951ba82da13edbe4f36c0666f11cf47a3f71f885f0`。任务的模型调用次数为 0，尚未开始 AI 识图或建模。

两端 ezdxf 均为 1.4.4，但本机 LibreDWG 为 0.14，生产镜像固定为 0.13.3。旧版 `dwgread` 和 `dwg2dxf` 均返回成功并生成 354686 字节 DXF，ezdxf 可打开其文档；完整预处理在展开 INSERT 图块引用时失败：引用名称 `*U` 对应的图块定义不存在。异常由 `_iter_expanded_entity` 转为 `DWGParseError`，被 CAD Agent 覆盖为笼统的预处理失败提示。

相同原文件经本机 0.14 完整处理成功：398 个原始实体，图块展开后 572 个实体，12 个原生尺寸对象，1 个渲染布局，未报告预处理警告。尺寸对象数量并不等同于图上全部文字标注数量。已查看实际生成的 PNG；本次检查不是三维模型准确性验收。

## 修复范围

- 部署转换器固定至 [GNU LibreDWG 0.14](https://ftp.gnu.org/gnu/libredwg/)，发布源码 SHA-256 为 `62ebb73b984f865960f20ed26619ea5f8789d5e3fd088fa40a2598384da81275`；补齐新版构建所需的 `pkg-config`。
- 保留缺失图块时的失败检查，不删除图块、不跳过几何来伪造解析成功。
- CAD Agent 和旧识图入口保留具体、安全的中文错误与恢复建议；前端兼容已保存的旧失败记录，状态栏不再直接显示 `dxf_parse_failed`。
- 解析失败时保留原始文件和重试依据，不暴露底层异常、文件路径或原图任意文本；错误提示不将兼容性问题断言为文件损坏。
