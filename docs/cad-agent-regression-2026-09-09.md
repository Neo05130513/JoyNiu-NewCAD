# 通用 CAD Agent 验收记录

日期：2026-09-09。实际模型服务：当前本地配置的 `gpt-5.6-sol`，reasoning `high`。

## 本轮改动

- 新图纸先独立转录可见文字、尺寸界线与基准，再进入工具循环：查看原图局部、记录来源尺寸、组合通用特征、执行 CadQuery、测量真实实体、查看真实三视图、修正和提问。空白文字建模直接进入工具循环。
- 读图器 v2 按墨迹与留白将每张栅格图分为最多四个内容区域，无法可靠分区时保留整图；区域不代表已识别的投影视图。最多四个请求并行，共享 180 秒并计入完整请求的 600 秒预算。单区瞬态错误仅重试一次，成功区域不重读，永久认证/权限/额度/上下文错误不重试；最终有区域未完成，整图仍失败。
- 每个区域保存各次尝试的安全诊断和已取得的候选。诊断只包含允许的错误类别、状态、耗时、事件/字符计数与用量，不包含供应商正文、推理文本或密钥；总超时后保留最后快照，晚到回调不能改写结果。
- 通用实体仅由受限 JSON 特征计划生成，不执行模型输出的任意 Python，也不按文件名、图片哈希或专用样本参数选取答案。
- 实体有效性、来源尺寸检查、AI 视觉对照和用户确认分别记录。检查范围包括整体尺寸、圆柱轴线/直径/位置、材料射线区间及实体数；没有测量的特征不能宣称验证通过。射线按实际实体包络取得完整截面，原探针窗口仅供诊断；短窗口不能隐藏额外厚度、外扩耳板或盲孔底，缺少完整覆盖证据的旧检查须重新执行。
- 未知尺寸保留为空；错误或缺失输入不生成替代模板。人工确认不能跳过失败检查，手改参数必须先重新建模和检查。
- 原图、计划、来源依据、实际检查和不可变修订保存在服务端。预览、三视图、STEP 绑定同一模型修订，旧修订不会覆盖当前模型。
- `edit_plan` 支持每批最多 12 个特征的增量草稿，引用校验通过后原子保存，失败批次不覆盖已有计划。每次保存或恢复草稿后进行最多 15 秒的实际 OCCT 构造检查，返回失败特征及轻量几何证据，不导出文件、不代表完整模型。完整来源 SHA 或文件顺序变化会清除旧依据、旧计划及局部；读图器版本变化也会清除旧依据并重读。只有完整来源与版本一致时复用转录，传输诊断和重复哈希不进入规划提示。
- 长任务在发出 `started` 前持久化 `runId`，浏览器断线后后台继续，GET 可恢复结果；服务重启把遗留任务标记为 `interrupted`。前端重试复用已存来源，确认与修改互斥并核对运行/修订，换图前自动保存旧版本。
- Responses 只消费最终 assistant phase 中的 CAD 动作，commentary 不执行；同一最终消息内多个 JSON 会被拒绝。阶段区分与历史重放遵循 [OpenAI phase 文档](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.5#phase-parameter)，多 JSON 拒绝是应用侧消歧规则。
- 图纸确认和 STEP 下载必须通过服务端独立复核门禁：来源正确、计划哈希一致、状态为 `consistent`、结构化 observations 非空、无 differences/questions/errorCode，并重新核对真实尺寸证据。存量 `ready` 和旧下载令牌同样受约束；纯文字保留 `not_applicable`。独立视觉意见仍可能错误，不能当作原图正确性保证。

## 此前真实浏览器与模型服务验证

隔离验收使用前端 `localhost:5174` 和 API `127.0.0.1:8012`，没有修改用户在 `localhost:5173` 的项目数据。

1. 新建“通用建模闭环验收”，初始预览为空。
2. 通过聊天创建 84×46×7 mm 矩形板，XY 中心为原点，底面 Z=0；在 X=±26、Y=0 设置两个 Ø11 的 Z 向贯穿孔，无圆角。实际实体和八项检查通过；点击确认后可导出 STEP。
3. 继续对话：“把两个贯穿孔直径从11毫米改成15毫米，其他尺寸、位置和结构保持不变。请更新模型并检查实际孔径。”该轮约 62.5 秒、3 次模型调用，实际孔径变为 15，板尺寸和孔位置不变；两孔轴线上没有实体材料，贯穿检查通过。
4. UI 显示新的真实 GLB；确认后的 2D 页面显示由同一个实体导出的前视、俯视和右视图。
5. 保存版本并在新浏览器页重新打开；确认状态、孔径 15、派生半径 7.5、对话和真实 GLB 保留。
6. 通过实际交付 API 下载 STEP，再由 CadQuery 重导并重新检查：84×46×7 mm、两个 Ø15 孔，全部已记录检查通过。
7. 重新打开后，手动将板厚从 7 改为 9。旧 GLB 立即失效、STEP 被锁定，点击“检查修改并更新预览”后约 79.9 秒、3 次模型调用完成。实测为 84×46×9 mm，两个 Ø15 孔的位置和贯穿性不变，再次允许确认。

## 图纸识别与执行器分开验收

通用执行器的几何回归覆盖双耳拱形支座、L 支架、旋转套筒、圆角及孔径修改。支座样本的已知尺寸仅用于测试夹具，证明通用特征能表达并构造该结构；这不等于 AI 能从原图独立正确读取这些尺寸。

对原始 `10.jpg` 的盲测没有提供专用配方或正确尺寸。早期运行仍误读部分半径、板厚和尺寸基准，并达到操作次数上限，没有开放 STEP。针对可复现的链路问题，已补充多张局部图的持续上下文、严格区分总尺寸与局部尺寸、实际工具结果保留，以及移除把固定四象限冒充已识别视图的先验。

自动识别不能以“OCCT 实体有效”代替“符合原图”。当前配置模型的复杂图纸识别能力仍需持续评测；不承诺任意图纸一次正确生成，也不把人工补充尺寸后的成功计作独立读图成功。

另做一次隔离的转录对照：同一模型、原图和主视图局部，仅要求转录可见标注及其尺寸基准，没有给正确数值或 CAD 计划/schema。约 53.9 秒，返回 R15、Ø13、40、9、R16、R28，并把 40 解释为孔水平中心线到底座下表面、9 解释为底座上下边缘间距。该单次样本支持拆分视觉转录与建模规划，不能据此宣称所有读图问题已解决。

此前完整页面转录在 90 秒预算内未完成；增加到 180 秒后，约 177.9 秒取得 12 条候选，但仍把板厚 9 读成 8。该完整运行约 600 秒超时，没有可执行计划或 STEP/GLB，不能计作读图或自动复刻成功。历史候选和摘要保留在 `apps/api/artifacts/cad-agent-regression/drawing10-source-transcription.json`、`drawing10-agent-audit.json`。

对已生成实体的独立 STEP 审计发现九项失败：内外拱圆心错误地抬高到底板顶面、底部多出封板、缺少两端 R15 安装耳圆弧、中央桥形不符等。检查结果位于 `/tmp/joyniu-cad-agent-qa/independent-audit-clean-final/independent-audit.json`。这说明“读对标注字符串”和“按正确空间基准构造”仍是两件事，模型自己建立的尺寸检查也可能漏掉错误。

**复杂原图的独立自动复刻尚未通过完整验收。** 已验证的是本样本的读图改善、通用工具循环、实际几何构造与检查、文字/参数修改、持久化及交付链路。剩余关键问题是空间基准与拓扑推断，以及独立视觉漏检；新增复核门禁不能代替这些能力。页面完成文案仅说明实体已生成、已记录尺寸检查通过，并提醒对照原图核对轮廓和未测特征，不复述模型的笼统成功声明。

显示层同时修复了板面中央的方形自阴影伪影：默认方向光阴影相机仅覆盖 ±5 mm，与毫米制 CAD 大模型不匹配。关闭阴影贴图后，同视角复核板面恢复平整，真实 STEP/GLB 几何没有改变。

## 当前 Chrome 项目的人工校正与旧入口修复

用户在 `localhost:5173` 的 `test2` 项目仍显示旧 `bracket_support_v1` 候选（厚度 8、孔径 30）。实际检查发现，旧文件没有自动接入新增的 CAD Agent，旧版上传工作台还存在旁路。因此增加显式“旧版图纸草稿 / 按原图重新建模”入口：有真实 File 时复用，只有文件名时要求选择原图，取消不改当前内容；重新建模前保留版本，用原始附件、空旧模型状态与空历史进入通用 Agent。旧模式名称统一到当前工作台。

这次直接在用户 Chrome 中先保存错误候选为 v01，再通过聊天输入逐视图人工核对的完整尺寸与空间关系；消息明确写明“Codex 人工读图修正，不是软件盲识别成功”。当前文件改为“圆弧双耳支座 · 人工校正”，并保存带来源说明的 v02。没有伪造自动识别、独立视觉复核或用户确认记录，也没有把样本答案接入生产读图器。

修正过程中还发现两处阻塞：完整参数草稿的“生成 3D”按钮原来进入导出操作；刷新后，保留原图文件名但已完成编辑的完整参数又被误判为缺少原图。现已改为直接重建 STEP/GLB，仅对 idle、无候选、有效参数且未中断的草稿免除重选；实际排队、分析和失败任务仍保留恢复门禁。

实际工作台点击生成取得 `geo_bc50da1e113a4164`，STEP `art_8522d9fce13747e2`，SHA256 `d3905b5c6ed54e8278e16b1fa668f4f1a5be5a173745c282adc12df69e0d4d3e`。从浏览器正常导出的项目 JSON 提取产物地址，下载后核对哈希，再重新导入本次 STEP 完成独立审计：**24/24 通过**，一个有效实体，110×50×55 mm，体积约 61984.676123 mm³，与人工参考实体的布尔对称差为 0。三个实际投影视图均已查看。产物与报告位于 `apps/api/artifacts/test2-manual-correction-2026-09-09/`（运行产物不入 Git）。浏览器重载后，12 个尺寸、人工校正名称和真实 GLB 均保留。
