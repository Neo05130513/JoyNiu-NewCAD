## 验收结果

- 全量前端：**446 项通过，0 失败**。
- 全量后端：**2062 项通过，0 失败**，耗时 273.06 秒；后续气泡输入防护新增测试另行通过。
- 原生二维/DWG/图库/气泡专项：50 项 Python 通过，10 项 DWG 用真实 LibreDWG 往返；气泡新增 3 项通过，随后原生二维/鉴权/DWG/气泡四模块合计 42 项通过。
- 12 个机械案例逐个运行真实内核并重新打开 STEP，不以计划 JSON 或预览占位算成功。
- 一次真实 AI 装配：25.873 秒，输入 9819、输出 181 token；隔离禁收费账户，未扣费。
- 两次真实带图阶段调用：63.219 秒；图片实际传入 Codex，已知尺寸作为 user 来源保留。
- Vite 生产构建通过；保留既有大包体积提示，未当作构建失败。
- 账号隔离、只读用户禁止写入、版本冲突、异常回滚、路径/大小限制和原有确认门禁均有自动验证。
- Linux ARM：同版本同 SHA256 的官方缓存源码完成 configure/make/静态链接；无编译器运行镜像中的四工具、严格 DWG 往返、中文块/布局/PDF 与非法补丁拒绝通过。正式 GNU 下载曾 TLS 超时；本次验证用相同哈希缓存，不冒充完整 API 镜像构建或部署。
- 本机隔离验收 API 为 `localhost:8016`，稳定构建预览为 [localhost:5180](http://localhost:5180)。现有 8012/5174 服务、持久 AI 配置及生产环境未由本任务修改。

## 已知边界

1. DWG 不是任意版本/任意专有对象无损承诺。常规标注、普通块、中文与多布局已验证；当前 LibreDWG 对属性块、HATCH、代理及自定义对象的写入不可靠时明确拒绝，保留原文件及完整 DXF，不通过炸开或丢实体冒充成功。详细条件见 DWG 专项报告。
2. 照片测试采用已知几何的合成图，验证实际带图读取/规划/构建阶段；没有据此声称实拍摄影测量精度、任意照片复刻成功或完整多轮交付审核已经通过。照片遮挡、厚度及未知尺寸继续询问和核对。
3. 手工特征编辑是独立设计，构建有效实体不会把原 AI 任务自动标为已确认；AI 装配仍保留待核验状态。制造放行和目标 CAD 软件验收规则不变。
4. 专业图库提供绘图构件，不包含建筑/电气/暖通规范、负荷或结构计算。基本装配配合不等同任意运动机构仿真。
5. 原生二维直接编辑范围在模型空间；纸空间和其他原始内容保留、预览和按布局打印。参数约束/图库的产品元数据保存在云图纸版本；普通 DXF 导出主要交换几何，原生尺寸/气泡关联通过 XDATA 保存。

本记录描述功能实现和实际验收范围，原始竞品审计仍作为实施前的历史对照保留。
