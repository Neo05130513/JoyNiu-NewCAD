# 三维零件编辑指南

生成模型后点击“编辑模型”，或从“设计工具 → 特征编辑”打开工作区。顶部为建模工具，左侧为特征/草图/实体树，中央为模型，底部为图档。双击树中的特征进入操作窗，双击草图进入绘图；操作完成后回到模型。

当前公网 IP 入口使用 HTTP，刷新页面后需要重新登录；项目和已保存模型仍在原账号中。HTTPS 入口才支持自动保持登录。

## 绘制和修改

- 点击“新建草图”，选择基准面、构造平面或模型的平面。用直线、圆弧、矩形、圆、椭圆、样条绘制轮廓；“新增外轮廓”增加另一块区域，“新增孔洞”从对应外轮廓扣除区域。
- 双击图上的尺寸输入数值或参数表达式；选择几何后添加所需约束。约束冲突时先调整尺寸或移除冲突约束，再完成草图。
- 独立草图保存后可在树中选择并用于拉伸、旋转、扫掠或放样。已有特征使用的草图和参考几何不能直接删除。
- 在模型中选边做圆角、倒角，选面做抽壳、移动面或新草图。按 Ctrl / Command 选择多项。操作窗显示本次选择、尺寸和预览，点击“完成”保存，点击“取消”保留原版本。
- 拉伸可选择添加、移除、相交、新建实体；新建实体不会自动与原实体融合。实体树可改名称、颜色、显示状态以及移动、旋转、复制、删除。

## 扫掠、放样和曲面

“拉伸”旁的菜单提供扫掠和放样。扫掠先画截面，再在路径画布中画直线、圆弧或样条，也可选择独立草图或构造螺旋线。截面应位于路径起点并与起始方向垂直。放样依次添加至少两个截面，每个截面可单独编辑形状和平面位置。多轮廓放样时，各截面的外轮廓与孔洞必须一一对应。

“偏移曲面”旁的菜单提供边界混合、样式曲面、连接和加厚。样式曲面创建控制网格后，可在模型视图拖动控制点，也可输入精确坐标。参考几何默认收起显示，点击树中的眼睛可显示或隐藏。

## 标准件和已有文件

“标准件”选择规格并填写位置，点击插入后会建立真实特征；完成后可修改尺寸和位置。“导入实体”支持 STEP/STP 和闭合 STL。STEP 使用文件中的单位，STL 需要选择原始单位。导入后可在实际面和边上继续建模；STL 保留原来的三角面结构。

## 标注、保存和交付

点击“PMI”选择尺寸、注释、基准、形位公差或粗糙度，直接在模型上拾取位置。关联标注跟随可识别的原面或边；若特征变化使关联不再唯一，重新拾取后完成。“解除几何关联”将标注改为独立坐标，需要自行核对后续位置。距离/半径/直径可设置上、下偏差。

完成操作后以当前版本保存。图档底部显示版本号；“导出 STP”下载该版本的实体，“导出 PMI 图”下载带当前视图和标注的 SVG。历史版本可以恢复成草稿，再完成为新版本。

“保存到 PDM”选择项目和名称，保存当前精确版本及其可编辑信息。打开 PDM 版本会新建独立图档，修改副本不会覆盖原版本。交付包从“交付中心”创建；图纸与制造审核状态仍需按项目要求完成。

## 资源社区

点击“AI 资源社区”可搜索、预览和下载公开模型，或将资源打开为自己的独立图档继续编辑。“发布当前模型”只分享当前已保存版本；名称、说明、几何、参数、特征名称、标注文字与必要的导入实体会公开，原项目、原图和账号记录不会公开。阅读共享范围并主动勾选确认后才发布。

在“只看我的发布”中可撤下资源，停止新的下载和副本创建；已经下载的文件和已创建的副本会保留。

## 遇到问题

未选择必要几何或尺寸无效时，操作窗会给出原因；修正后重试。“完成”需要等待当前预览和实体检查完成，处理期间不要重复点击。失败不会替换原保存版本。重新打开失败时使用重试，确认模型已载入后继续编辑。
