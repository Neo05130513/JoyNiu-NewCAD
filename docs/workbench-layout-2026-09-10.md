# 建模工作区布局调整与部署记录

## 问题与改动

旧工作区固定为一屏高度，识别状态和记录增加后，会压缩下方对话、三维预览和参数区。现在页面自然向下延伸，桌面对话与预览区域至少高 720px；识别与检查记录默认折叠，必要的状态和确认入口继续显示。

- 常见笔记本宽度采用左侧对话、右侧大预览，参数与检查在下方全宽展示；点击“参数与检查”可直接跳转。
- 宽度达到 1600px 时恢复宽敞的三栏；不超过 1000px 时纵向排列，避免横向挤压。
- 对话文字、消息区域和输入框加大；参数按可用宽度排列成三列、两列或单列。
- “放大预览”隐藏周边工作区，保留同一个三维查看器。点击收起或按 Esc 返回时，保留模型视角、缩放、输入草稿和进入前的页面位置。
- 本次仅调整前端布局与浏览交互，没有修改建模和交付确认规则。
