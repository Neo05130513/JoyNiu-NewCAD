# 客户操作路径验收与优化

2026-09-13：按照客户从首页进入工具、登录、编辑、返回、保存重开的实际路径检查前端。

## 已修复

- 二维、三维编辑器增加明确的「返回主页」，手机端也保持可见。正在绘制或修改时沿用草稿保护流程，用户可继续编辑或明确放弃输入。
- 工程设计和交付中心增加就地登录按钮；工具发起登录后优先回到原工具，并保持账号工作区隔离。
- 二维新建、导入、打开成功后关闭文件菜单；支持 Escape 和点菜单外关闭。切换图纸重置到模型空间，避免沿用另一张图纸的布局。
- 手机二维页显示图纸名称和保存状态；文件菜单桌面显示文字标签。
- 空任务列表增加「开始设计」，空交付来源增加二维、三维创建入口。
- 账号页长邮箱换行，不再撑出手机屏幕；文档正文和文件类型补充稳定的读屏名称。
- 照片与标定说明进入建模会话时返回实际附加结果；被任务状态或附件验证拦截时，不再显示添加成功。

## 验证

- 16 个页面分别在 1440×960、390×844 走查：32 次检查无横向溢出、无页面脚本错误。
- 二维真实接口操作：直线、椭圆、移动、复制、撤销重做、分组、剪贴板、纸空间布局、DXF 下载、重开修订，以及新建后自动关闭菜单。
- 客户路径：工具登录回跳、菜单退出、未完成绘制返回保护、三维手机返回主页、新建项目/文档、保存版本、重命名、删除恢复、下载正文、刷新恢复。
- 工程设计、交付中心、我的任务的登录回跳通过；照片标定参数和附件进入消息框通过，未发送付费建模请求。
- 前端完整测试 788 项通过，`VITE_API_BASE=/api/v1 npm run build` 通过；执行日志保留在本次本地验收目录。结构化结果和关键截图见 `docs/evidence/customer-ux-2026-09-13/`。

这是前端操作与已列明流程的验收，不等于全部 CAD 内核、付费 AI 生成或生产加工流程完成验收。本次发布只替换 web 镜像，API、CAD 出站服务和客户数据保持现有版本；公网结果在发布后补记。
