# 客户使用说明

## 把一套设计交付给他人

打开「交付中心」，选择已保存的工程设计、特征版本、二维图纸或已确认的 AI 结果，填写名称和备注后创建交付包。装配会自动关联子零件，已有工程图和 BOM 一并纳入；只有实际存在并通过校验的文件才会出现。

在「已保存交付包」中重开结果，核对每个文件旁的来源与版本，再下载整包 ZIP 或单个文件。ZIP 内的 `manifest.json` 记录来源关系、版本和 SHA-256；单文件下载名包含来源前缀，便于区分装配和零件。换设备登录同一账号后仍能找到已封存的包。

封存后继续修改设计不会改变原交付包；要交付新版，应重新创建一个包。封存只锁定文件版本，尺寸、材料、公差、图纸排版和制造用途仍需按项目要求验收。尚未通过确认的 AI 结果不能借交付中心下载。

适用流程：运营开通账号 → 线下充值 → 上传图纸 → 补充与核对 → 确认模型 → 导出与客户 CAD 验收。请以页面上的实际服务状态、已发布规则及你接受的版本为准。

## 第一次使用

1. 使用运营为你开通的账号登录，核对显示的账号确实属于自己。
2. 阅读“服务与积分规则”。正式文本尚未齐全时联系运营确认，不能把帮助说明当作已经发布的服务约定。
3. 当前由运营线下确认收款并在后台充值，基础兑换为 **10 元充值 1000 积分**。付款前核对客户账号和运营提供的收款信息。
4. 到“积分与订单”检查充值单、到账流水与可用余额。若存在待补缴，充值先清偿待补缴，可用余额可能小于充值积分。
5. 新建项目与零件文件，开始上传。不要把账号密码、收款密钥或无关个人资料写入图纸和聊天。

## 什么图纸适合先试

建议先用尺寸完整、视图清晰的单个机械零件：轴套、支座、板件等。每份图纸应说明单位、需要建模的零件、主要视图、孔槽和台阶尺寸。图纸未定义的结构应先补充确认。复杂装配、任意曲面、缺少关键尺寸的扫描图，需要逐项判断适用性。

当前上传入口每次最多 **4 个文件，每个不超过 20 MB**，允许 DWG、DXF、PDF、PNG、JPG/JPEG、WebP、GIF、BMP。可上传的扩展名不代表所有文件版本和复杂度均已验证。PDF 解析有页数与像素限制，多页文件请先提取本零件所需页；上传后在“图纸核对”确认相关视图齐全。DWG 失败时可从原 CAD 软件另存或导出清晰 PDF/PNG，不能只改扩展名。

## 按步骤完成一次转换

1. 在 3D 建模页上传图纸，说明零件范围和需要保留的特征。保留任务编号。
2. 通过“我的任务”查看排队和处理状态。刷新或离开页面不会取消后台任务；需要停止时使用取消按钮，并等待服务端确认。
3. 若状态为“待补充”，按问题补充尺寸或结构依据。不要把模型预览或生成的草稿当作已确认成果。
4. 查看 3D 模型，切换前、顶、侧视角，必要时剖切。进入“图纸核对”，逐项核对中文参数与原图标注。
5. 核对单位、总长宽高、孔径与位置、槽宽槽深、壁厚、台阶、螺纹表达、实体数量及省略特征。修改后重新构建并核对新版本。
6. 确认当前模型，再下载 STEP 和当前版本核对报告。保存版本和项目备份。
7. 在实际使用的 NX、SolidWorks、Creo 等软件打开 STEP，复查实体数量、单位、包络尺寸和关键尺寸；记录软件及版本、文件名、任务编号和检查结论。

STEP 是交换实体，不承诺保留客户 CAD 软件的原生特征树。核对报告记录已检查范围，不替代设计、工艺或制造放行。

## 积分怎么扣

收费启用后按实际 token 用量、公布单价及管理员设置的倍率结算。不同模型、普通输入、缓存输入、输出可能有不同单价，以任务关联的规则版本为准。

- 成功候选，即待确认 `review_required` 或已确认 `ready` 的尝试进入结算。候选仍需客户核对。
- 待补充、失败、取消、中断的本次尝试不扣积分。
- 缺失用量或计价依据的记录待核账，不将未知用量当作零或猜测扣分。
- 余额不足时先扣现有余额，其余记为待补缴；后续充值优先补缴，有待补缴时不能开始新的收费任务。
- 查看、旋转、下载已有成果不会重复结算；修改、重试会建立新尝试，按本次实际结果和对应规则结算。

## 到哪里查问题

在“支持与工单”提交问题，填写任务或充值单号及实际差异；保留工单编号，在页面查看后续回复。充值未到账、退款、发票选择“积分与订单”；尺寸与结果问题选择“建模与图纸”。退款受理或审核通过不代表钱已退回，须以实际线下凭证和处理记录核对。积分补偿与现金退款分别记录。

附图授权默认不勾选，关联本人任务后才可选择，之后可撤回。当前工单只保存授权记录，不开放管理员原图下载。工单回复不会发送邮件或短信；支持时间与联系方式由实际运营安排，页面未公布的时效不作承诺。

## 保存、恢复与删除

顶部“已保存”表示当前修改已写入云端。网络异常时保留浏览器草稿；多个窗口发生冲突时先导出本地备份，再选择如何恢复。回收站可恢复误删的项目，备份中的参数、对话和版本不替代单独保存的 STEP、原图等文件。

需要删除数据时，在“支持与工单”点击“申请删除数据”，选择原图、模型、项目/聊天/版本、账号、工单、备份等范围，并提供任务编号、文件名及时间范围。运营先核对身份、范围和保留要求，再提供人工处理回执。回执会列出实际处理范围、仍保留的信息及原因、保留期限、备份安排与记录编号。

回收站、撤销链接、撤回附图授权和物理删除分别处理；提交或关闭工单不会自动删除数据。若要调整或撤回申请，请追加说明，等待运营确认当前处理进度。
