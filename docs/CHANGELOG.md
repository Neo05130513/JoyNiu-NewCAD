# 变更记录

## v0.1.0 · 2026-08-29

### Added

- 创建 `JoyNiu-NewCAD` 独立开发分支。
- 固化 CurrentCAD 深度体验证据与产品规格。
- 初始化 React + Vite 单页工作台。
- 实现 AI 参数解析、轴类零件参数编辑、特征树和三维 SVG 预览。
- 实现 2D 工程图、装配、标准件库、项目管理和导出交互。
- 使用 localStorage 保存当前项目与操作历史。

### Known limitations

- 当前几何是浏览器端演示内核，STEP/DXF 为可审计交互样例，不替代 OCCT/CadQuery 生产实体。
- 2D AI、云端账号/PDM、多用户协作、CAM 仿真尚未接入。
