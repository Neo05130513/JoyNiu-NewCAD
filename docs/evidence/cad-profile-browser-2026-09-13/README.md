# 任意轮廓放样与图形扫掠：真实本地浏览器验收

2026-09-13；Chromium headless，1440×1000；页面 http://127.0.0.1:5186，独立合成 QA 账号。无模型调用，无生产操作。使用当时已有 dist，验收期间未构建或修改业务源码；之后 root 已重建，未把此证据冒充重建后的再次测试。

## 已执行的用户路径

1. 新建空图档 → 拉伸更多工具/放样 → 绘制矩形截面 → 完成草图 → 绘制第二个椭圆截面 → 完成草图 → 在可见表单将第二截面原点 Z 设置为 15 → 完成并保存 r1 → 点击导出 STP。
2. 新建空图档 → 拉伸更多工具/扫掠 → 鼠标绘制非圆矩形截面 → 完成草图 → 在图形路径中点取直线、三点圆弧、直线 → 在可见坐标表精确校准起点 [0,0,0]、直线终点 [0,0,20]、圆弧经过点 [5,0,25]/终点 [10,0,20]、末端 [10,0,0] → 完成并保存 r1 → 点击导出 STP。

鼠标绘制的轮廓坐标保留实际值，未把近似点击说成精确整数尺寸。记录中的矩形扫掠截面是 2×1.028 mm，截面积 2.056 mm²。脚本没有通过 API 或状态注入预制计划；响应监听只记录页面真实提交结果。`actions.cjs` 保存实际交互动作，不包含账号凭据。

## 结果

- 2 次 commit 均 HTTP 200，页面错误 0，CAD HTTP 错误 0。
- 放样 STEP：有效、1 实体、7 面；V=759.2814491838773 mm³；高度约 15 mm。
- 扫掠 STEP：有效、1 实体、10 面；V=114.5355724789045 mm³。独立解析核对截面积 2.056 × 路径长度 (40+5π)，误差约 1.4×10⁻¹² mm³。
- 两个下载文件均由独立 Python 进程用 CadQuery/OCCT `importStep` 回读，并核对保存响应体积、实体有效性、实体数和文件 SHA-256。详细尺寸与 SHA 在 `step-readback.json`。
- `accepted-records.json` 是两次真实保存的返回记录，包含准确特征、约束、路径、截面平面和来源状态；没有登录凭据。

这是两条合成件本地交互链路的通过证据，不代表所有轮廓/所有输入均能成功，也不是生产复验或制造放行。`drawingAgreement=not_checked`、`productionReady=false` 保持原值。
