# 三维完整编辑器公网鼠标验收

目标：正式 r8 http://122.51.168.205/，独立 Chromium、专用合成账号，无模型计划注入，未使用用户的 CurrentCAD 文档。

实际鼠标绘制 40×30 主轮廓、圆孔半径5→7、10×10第二外轮廓，拉伸5，两个实体；建立偏移平面和螺旋线；曲面网格中心Z6→7.337706真实拖动；在实际模型面点选两点创建关联PMI、保存r5并下载SVG。重新登录恢复同一模型后，双击草图的图上尺寸，将宽40→45保存r6，PMI锚点X31.688498402555922→35.64956070287541；再次重开r6并检查390×844手机面板开关，无页面横向溢出，浏览器JavaScript错误0。

公网HTTP的现有安全策略不发持久刷新Cookie，刷新后需要显式重新登录。初次测试脚本误以为可自动保持登录，等待标注超时；确认capabilities与403说明后，按真实登录流程继续验收相同设计与版本，没有重建替代文档。此记录证明模型持久化，不宣称HTTP自动保持登录。

两个实际浏览器下载的STEP均经独立CadQuery/OCCT导入：原模型两个有效实体、13面、体积5730.309799870473 mm³；修改后两个有效实体及独立曲面、14面、体积6480.309799870463 mm³。与解析值误差小于1e-6 mm³。SVG含实际模型截图及标注文本。

最终界面见 joyniu-complete-desktop-final.png 与 joyniu-complete-mobile.png。提交链及重登后重开证据在两个records.json中。初次脚本的HTTP登录等待失败不会被计作会话保持通过。
