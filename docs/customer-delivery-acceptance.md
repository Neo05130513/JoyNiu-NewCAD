# 客户图纸范围与交付验收

## 当前可以承诺的范围

本版本提供图纸上传、源图核对、参数与候选模型、确认后 STEP 导出、核对报告及账号项目保存。首批按具体图纸确认可处理范围，建议选尺寸齐全的单个机械零件；不能依据格式解析成功承诺任意图纸可完整生成，也不能把已有练习图的候选模型当作客户盲测验收结果。

| 输入 | 当前代码边界 | 已有证据与限制 |
| --- | --- | --- |
| DWG | 每文件 20 MB；经 LibreDWG 转 DXF 后解析、展开和渲染 | 已有一份 AC1032 / AutoCAD 2018+ 原文件的完整二维解析证据；不是全部 DWG 版本认证，也不是该图三维交付验收 |
| DXF | 每文件 20 MB；依赖实际实体、图层、图块和文字支持 | 需确认图块、标注和视图齐全；原图查看不等于可直接编辑并写回原始 DWG/DXF 实体 |
| PDF | 每文件 20 MB；预处理默认最多渲染 20 页，另受像素和渲染大小约束 | 上传页数不等于全部页内容已被建模；拆分到本零件相关页，并核对实际展示的视图 |
| 图片 | PNG、JPG/JPEG、WebP、GIF、BMP；每文件 20 MB | 优先清晰静态图。低清晰度、裁切标注、扫描倾斜或多义线条须补充；动画文件不承诺逐帧识别 |
| 每次请求 | 最多 4 个文件 | 多文件应为同一建模上下文；不要在一单中混入多个无关零件 |

范围来源：`cad_agent_api.py` 上传白名单和数量限制、`ai_proxy.py` 文件限制、`pdf_preprocessor.py` 默认配置。部署运行时的实际报错与更严格资源限制优先。

## 一张图的验收记录

由运营和客户共同填报。图纸授权与客户实际软件验收需要真实参与，不能由模型代理代填为通过。

| 项目 | 待填写 |
| --- | --- |
| 客户与经确认的图纸使用权限 | [客户编号、授权范围、授权日期] |
| 输入与范围 | [原文件名、SHA-256、页码、单位、零件数量、建模范围] |
| 任务与版本 | [任务编号、尝试编号、当前模型版本、确认时间] |
| 补充与修改 | [问题、客户补答、修改原因、原图未定义处] |
| 交付文件 | [STEP 文件名、SHA-256、核对报告文件名、备份位置] |
| 实体与包络 | [实体数、总长/宽/高、体积检查结果] |
| 关键尺寸 | [孔径/孔距、槽宽/深、壁厚、台阶、角度、螺纹表达的实测值] |
| 客户 CAD | [软件、版本、导入选项、单位、导入结果及复查截图/记录] |
| 未验证或省略范围 | [小圆角、公差、螺纹实体、制造属性等] |
| 结论 | [待补充 / 待修改 / 指定范围通过；客户核对人、日期] |

同一文件重复下载无需新建结算。后续修改或补答应关联原任务，记录本次实际尝试与费用状态，不把旧版本核对结果复用到已改变的几何。
