## 本轮修复

1. HTTP 无刷新 Cookie 时，退出未向服务器传递访问凭证。现在退出明确撤销当前会话；新 HTTP 登录也建立独立服务器会话，保留其他设备登录。
2. 通用请求收到响应头便解除超时，响应正文卡住会持续等待。超时和取消现覆盖完整正文读取。
3. 原图、3D GLB、2D 投影链接过期时，重试仍使用旧地址。现按当前任务及修订认证续期，原图/投影下载读取实际文件；不因签名失效而触发 AI 或实体重建。
4. 原图组件缓存遮蔽父组件提供的新链接。现按链接撤销代次及到期时间选取最新资源，保留缩放和平移。
5. 查看器仅处理正式实体的 404，候选模型的 403/404 无法恢复。现覆盖候选和正式 GLB，校验任务、修订与 URL；迟到响应不能改写其他文件。
6. 装配可能使用已经失效的实体包络。现拒绝用旧模型边界得出当前检查结论。
7. 先恢复子文件再恢复父项目会拆成多个同名项目。现恢复到同一原项目并保留先恢复后的修改。
8. 空云工作区规范化丢失回收站/导入标记、重载可能选中内容不可用旧文件。现保留状态并选择可用文件。
9. 读取备份期间切账号或卸载后，迟到回调仍会导入。现使旧操作失效，并明确显示导入被拒、历史恢复和下载错误。
10. 空白零件重命名的回调可能把空模型变成仅有名称的对象；忙碌状态拒绝回收恢复未返回失败标志。现保持空模型并正确报告拒绝。
