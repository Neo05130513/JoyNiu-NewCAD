# 独立管理后台验收 · 2026-09-10

本轮将管理员功能集中到独立的 `/admin` 后台，补齐客户与任务运营页面，并发布到 `http://122.51.168.205/admin`。使用现有管理员账号登录；普通客户不能访问后台接口。

## 已交付功能

| 模块 | 已实现行为 |
| --- | --- |
| 独立后台 | 独立登录与导航、按权限显示菜单、直接链接与刷新、返回客户工作台、小屏导航；切换后台保留已打开客户工作区的任务与草稿状态 |
| 运营概览 | 真实客户与任务统计、按状态查看待处理任务；财务指标按权限展示 |
| 客户管理 | 搜索、启用状态筛选、分页；客户详情关联所属任务、积分与订单摘要、工单 |
| 建模任务 | 搜索、状态与客户筛选、分页；查看真实状态、阶段、模型配置、耗时、请求次数、已记录用量及安全错误类别 |
| 任务停止 | 具备权限的人员填写原因后请求停止；幂等处理、操作留痕，等待实际工作进程确认，不伪造终态、不触发 AI 重试 |
| 积分与订单 | 接入已有积分流水、订单、人工调整等管理功能；按财务权限控制操作 |
| 客服工单 | 接入已有工单管理，客户详情可直接打开对应工单 |
| 系统管理 | 计费规则、服务条款、后台与账号权限、账号安全 |
| 系统状态 | 当前供应商、模型及推理强度、CAD 内核、数据库、磁盘、队列及计费状态；缺失能力明确标为未配置 |
| 操作审计 | 汇总运营、账号、积分和工单审计；可筛选与分页；客户/任务详情读取留痕 |

后台诊断不返回客户图纸、提示词、完整计划/代码、原始堆栈、密钥或签名下载地址。旧任务缺失的用量显示“未记录”，不计算为零；供应商请求次数、明确记录的重试次数、计量调用数分别展示。

## 权限分工

| 角色 | 业务范围 |
| --- | --- |
| 管理员 `admin` | 全部后台功能；分配账号权限、计费规则与条款管理 |
| 运营 `ops` | 概览、客户、任务、请求停止任务、系统状态 |
| 财务 `finance` | 概览、客户、积分/订单读取与管理、积分调整 |
| 客服 `support` | 客户、任务读取与工单处理；不读取财务详情 |
| 审计 `auditor` | 概览、客户、任务、系统、积分读取与操作审计；无业务写权限 |

前端菜单与服务端实际授权同时生效。停用账号、降级权限后，旧访问凭证不能继续保留原权限；最后一名有效管理员仍受保护。已有工程角色不会自动得到后台权限。
