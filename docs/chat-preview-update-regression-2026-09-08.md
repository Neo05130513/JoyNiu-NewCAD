# 对话修改与中央预览同步回归

日期：2026-09-08。针对“对话里修改后，中间预览不变化”进行排查与修复。

## 查明的问题

- 对话回复原先只按“存在参数补丁”判断修改成功；空补丁、相同参数和不受支持字段也可能提示“修改已应用”。现在依据实际可应用的参数差异反馈结果，尺寸冲突时明确提示预览暂停，材质等属性修改说明不改变几何尺寸。
- 后端兼容解析原先会让空的 `parameter_patch` 覆盖有效的 `parameterPatch`，也忽略部分候选容器。现在按字段规范化后合并，保留白名单和类型校验；顶层旧识别容器只在其它补丁容器缺席时兼容读取。
- 图纸候选的后续文字修改只更新可见模型，确认数据仍可能保留旧尺寸。现在同步更新确认和生成所用的候选快照，保留未修改尺寸及人工来源；切换配方时解除旧图纸及其审核状态。
- Viewer 原先仅依赖 `stale` 标志选择 GLB。现在还核对生成参数与当前模型；不一致时显示最新参数预览。
- 每次刷新网格都会自动适应尺寸，掩盖放大后的视觉变化，并重置旋转视角。现在同一零件编辑保留观察距离和方向；首次载入、切换配方和“重置视图”仍适应模型。
- 夹紧座主段深度的合法值 47 和 50 曾被裁成相同尺寸；已移除该类预览截断。
- 轴键槽原先通过叠加方块提示，槽深变化藏在实心轴内。改为带真实孔和键槽轮廓的分段挤出，不增加布尔运算依赖。

- 后端 `test_ai_proxy.py`：86 项通过（新增 17 项）。
- `npm run build` 和 `git diff --check` 通过；构建仍有原有大 bundle 提示。
- 几何射线测试：轴槽深 3 → 5，槽底 Z9 → Z7；通孔沿轴线贯通，槽宽、槽长改变实际切除范围。
- 夹紧座合法主段深度 47 → 50，底板真实轮廓变化；旧 GLB 拦截、相机方向及距离保持均通过。
- 真实浏览器 + 真实 AI：轴长 70 → 100，参数面板、对话修改记录、中央预览同时改变，画面中的轴明显变长。
- 固定 AI 响应 + 真实 FastAPI/CadQuery：支架生成真实 GLB 后，底板长 100 → 140，新 GLB 及 OCCT 包络同步为 140 × 50 × 40。
- 固定 AI 响应浏览器回归：空补丁明确显示“预览未改变”；待确认图纸候选经文字改为 140 后，候选摘要、参数面板均为 140，点击确认也未回退。

## 外部服务现象与边界

真实 AI 中转服务测试中出现过 `AI provider returned a non-completed response`，本轮没有可应用参数，重试后成功返回 `length: 100`。这是另一个预览保持原样的原因；现已提供中文失败说明，不将未完成的远程输出当成成功修改。不能据此确认用户此前具体哪一次对话命中了哪种情况。

本次没有扩大支持的 CAD 配方，也没有把本地参数预览当作生产 STEP。固定响应仅用于本地测试，未加入应用运行代码；真实服务配置未修改。
